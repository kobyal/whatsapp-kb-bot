# תסריט קריינות — demo v2 (עברית)

קובי מקריא. שורה אחת לכל קטע (beat). הזמנים הם מ-`marks.json` של הבנייה הנוכחית; 
"מקס' מילים" = (משך הקטע פחות חצי שנייה נשימה) × ~2.3 מילים/שנייה. אין צורך למלא את כל הזמן — עדיף לסיים מוקדם מלחרוג.

הקלטה בפעם אחת: לקרוא ברצף מ-t=0 ולהתחיל כל שורה בזמן ההתחלה שלה (הסרטון פתוח ליד). 
הקלטה לפי קטעים: קובץ `beat1.m4a` … `beat7.m4a`, כל אחד רק המשפט שלו; `mix_narration.sh --beats` ממקם אותם.

## הטקסט בלבד (לקריאה)

1. (0.0s) בוט תמיכה לוואטסאפ — בקבוצות ובפרטי.
2. (3.0s) יואב שואל על ה-VPN. הבוט מוצא תשובה מאומתת ועונה, מסומן כאוטומטי.
3. (8.4s) דנה שואלת משהו שאין עליו תשובה מאומתת. הבוט שותק — בלי ניחושים, בלי רעש.
4. (14.7s) יואב שולח צילום מסך. הבוט קורא את התמונה ועונה מאותו מאגר.
